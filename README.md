Finetune LLM is a small learning project for parameter-efficient fine-tuning. It takes
[Mistral-7B-Instruct-v0.3](https://huggingface.co/mistralai/Mistral-7B-Instruct-v0.3), loads it in 4-bit and trains
LoRA adapters on a handful of question–answer pairs, so the model answers questions about Scrum in the voice of
*Marcus Productivus Maximus*, a Roman legionary turned Scrum Master. The point is not the persona, but seeing the
whole loop once: data → training on a free GPU → inference → upload to the Hugging Face Hub.

## Features

- 🧾 **Tiny dataset**: 17 hand-written instruction/answer pairs in German, generated by `src/01_dataset.py`
- ⚡ **QLoRA-style training**: 4-bit NF4 quantisation (bitsandbytes) plus LoRA adapters (peft) on the attention
  projections, trained with TRL's `SFTTrainer`; fits on a free T4 GPU
- 💬 **Interactive inference**: chat with the fine-tuned model, run a set of test questions, or export the model
- ☁️ **Runs on Colab**: a notebook that clones the repo, trains, tests and optionally uploads to the Hugging Face Hub

> [!NOTE]
> Built in July 2026 as a personal experiment to learn LoRA fine-tuning hands-on. Code comments, script output and
> the training data are in German.

## Quick start

### Google Colab (recommended)

Open the [notebook](colab_legionaer_finetuning.ipynb) with the badge above, switch the runtime to a **T4 GPU** and
run the cells top to bottom. Training takes about 20–30 minutes.

### Local (Linux or Windows with an NVIDIA GPU)

```bash
pixi install
pixi shell

python src/01_dataset.py    # write data/legionaer_training_data.json
python src/02_train.py      # train LoRA adapters → models/legionaer-final/
python src/03_inference.py  # chat, test questions or export
```

`make dataset`, `make train` and `make inference` run the same steps; `start_training.sh` runs all three in a row.
Without a GPU, training takes hours and is not recommended. The Pixi environment is defined for `linux-64` and
`win-64` only; on other platforms install `requirements-kaggle.txt` with pip.

To upload the adapters to the Hugging Face Hub, copy `.env.example` to `.env`, set `HF_TOKEN` and run
`make upload` (see [DEPLOYMENT.md](DEPLOYMENT.md)).

## How it works

1. **Data**: each example is an `instruction` (a question about Scrum) and an `output` (the legionary's answer).
2. **Load**: the base model is loaded in 4-bit, so its ~14 GB of weights fit into a few GB of VRAM.
3. **Adapt**: LoRA adds two small matrices (rank 16) next to the frozen query and value projections. Only these are
   trained, well under 1 % of the parameters.
4. **Train**: 3 epochs, batch size 4 with 2 accumulation steps, learning rate 2e-4 with 10 % warm-up.
5. **Use**: `03_inference.py` loads the base model again, puts the adapters on top and generates answers with the
   Mistral prompt format `<s>[INST] … [/INST]`.

Example answer to *"Was ist ein Sprint?"* from the training data:

> Hark! Ein Sprint, mein Freund, ist wie ein Feldzug unserer Legionen! […] Für Rom! ⚔️

## Configuration

The hyperparameters are set as constants at the top of the scripts:

| Setting | Value | Where |
|---|---|---|
| Base model | `mistralai/Mistral-7B-Instruct-v0.3` | `src/02_train.py`, `src/03_inference.py` |
| LoRA rank / alpha / dropout | 16 / 32 / 0.05 | `LORA_CONFIG` in `src/02_train.py` |
| LoRA target modules | `q_proj`, `v_proj` | `LORA_CONFIG` |
| Epochs / batch size / grad. accumulation | 3 / 4 / 2 | `TRAINING_CONFIG` in `src/02_train.py` |
| Learning rate / warm-up / weight decay | 2e-4 / 0.1 / 0.01 | `TRAINING_CONFIG` |
| Generation | 256 new tokens, temperature 0.7, top-p 0.9 | `src/03_inference.py` |

`config.yaml` collects the same values in one place, but the scripts do not read it yet.

## Repository structure

```
finetune-llm/
├── src/
│   ├── 01_dataset.py                 # write the training data
│   ├── 02_train.py                   # 4-bit model + LoRA + SFTTrainer
│   └── 03_inference.py               # chat, test questions, export
├── data/legionaer_training_data.json # 17 training examples
├── colab_legionaer_finetuning.ipynb  # end-to-end run on Google Colab
├── hf_login.py                       # Hugging Face login and upload
├── setup.py                          # create folders and .env
├── config.yaml                       # hyperparameters (reference only)
├── pixi.toml                         # environment (Pixi)
├── requirements-kaggle.txt           # pip requirements for Colab/Kaggle
├── Makefile, start_training.sh       # shortcuts
└── *.md                              # guides: quick start, Colab + Git, deployment, integration
```

Trained models are written to `models/` (ignored by Git): checkpoints in `legionaer-sft/`, the final adapters in
`legionaer-final/` and the export in `legionaer-deployed/`.
